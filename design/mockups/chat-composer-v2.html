What each number is

  1. 1
    "+" attach and @ for context in the placeholder — new. Opens panel B: a picker over files, folders, images, installed subagents, and skills/commands, reusing the ContextMenu primitive we already have. The two toggles at the bottom (Plan first, and a Goal mode we haven't spec'd yet) are per-message opt-ins, separate from the project-wide permission-mode setting in Section Settings.
  2. 2
    Agent / Lead picker — enhanced. Same boolean the Lead chip already sets, but the description you currently only see on hover after picking now shows for both options before you pick, in panel C. Copy is pulled straight from the existing title text in ChatComposer.tsx, not invented.
  3. 3
    Uncommitted count on the checkout chip — enhanced. The branch Select already annotates rows ("checked out", "remote", "not found"); panel D adds one more line to the current-checkout row using data we already read for the git panel.
  4. 4
    Empty-state headline + Suggested list — new. An unstarted pane today is a blank scroll area; this fills it with a short heading and a handful of clickable prompts (recent tasks, to start).
Deliberately not carried over: the project switcher's "Connect SSH" row (no remote-project support in Chewo), splitting "Local vs Worktree" into its own control ahead of the branch picker (this app merged that into one control on purpose — see the comment above SessionSetupRow in ChatComposer.tsx), and the multi-vendor model list with per-model pricing multipliers (different business model — our model list is per-CLI catalog, not a cross-vendor marketplace).
